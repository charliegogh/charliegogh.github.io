# rollup 工程构建

本工程用于构建面向浏览器或 Node.js 端的 **SDK 类工具包**，例如前端通用工具库、监控埋点 SDK、JWT 工具模块等，采用 [Rollup](https://rollupjs.org/) 构建输出，可同时支持 `ESM`、`UMD`、`CJS` 等格式。

---

## 为什么使用 Rollup？

| 特性             | 描述                                         |
| -------------- | ------------------------------------------ |
| ✅ 极致轻量         | 与 Webpack 相比更专注于“打包库”而非应用，输出体积更小           |
| ✅ Tree Shaking | 原生支持 ES Module 的“按需打包”能力                   |
| ✅ 多格式输出        | 一次构建生成 UMD + ESM + CJS，满足浏览器、Node、CDN 多端适配 |
| ✅ 插件机制强        | 丰富的插件生态，支持转译、压缩、样式处理等                      |
| ✅ 快速构建         | 编译速度快，适合开发通用模块、纯函数类库                       |
